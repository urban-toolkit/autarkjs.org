# API Reference Docs — How to Regenerate

The API reference for each autark library lives in `guide/api/{lib}/` as VitePress-processed markdown, generated by TypeDoc with the `typedoc-plugin-markdown` plugin.

## Source libraries and their TypeDoc config

| Library | Entry point | TypeDoc config |
|---|---|---|
| `autk-db` | `src/main.ts` | `autk-db/typedoc.json` |
| `autk-map` | `src/` (all files) | `autk-map/typedoc.json` |
| `autk-plot` | `src/main.ts` | `autk-plot/typedoc.json` |
| `autk-compute` | `src/main.ts` | `autk-compute/typedoc.json` |

Each uses plugins: `typedoc-theme-oxide`, `typedoc-plugin-markdown`. Output dir: `docs/`.

## Steps to regenerate and import

1. In each library folder (e.g. `autark/autk-db/`), run:
   ```bash
   npx typedoc
   # or: npm run docs  (if the script exists)
   ```

2. Copy the generated `docs/` to `autarkjs.org/guide/api/{lib}/`:
   ```bash
   rsync -a --exclude='_media' autark/autk-db/docs/ autarkjs.org/guide/api/autk-db/
   mv autarkjs.org/guide/api/autk-db/README.md autarkjs.org/guide/api/autk-db/index.md
   # Repeat for each lib
   ```

3. Remove the broken logo image tags from each `index.md`:
   - Delete the `<div align="center"><img src="_media/logo.png" .../></div><br>` block

4. If new classes/interfaces/types were added, update the sidebar in `guide/.vitepress/config.ts` under the `/api/{lib}/` key.

5. Run `npm run dev` to verify everything loads correctly.

## Notes

- Relative links between TypeDoc files (e.g. `[SpatialDb](classes/SpatialDb.md)`) are preserved when the folder structure is kept intact — VitePress resolves them correctly.
- No frontmatter needed in the TypeDoc files — VitePress processes plain markdown with the full theme.
- Dark/light mode works automatically via VitePress (no `theme-sync.js` or iframes needed).
- The `_media/` folder in TypeDoc output contains only a logo image — exclude it during copy.
