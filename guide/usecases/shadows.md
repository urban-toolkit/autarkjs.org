# Urban Shadow Analysis

This case study visualizes **accumulated building shadows** across the Chicago Loop, combining shadow measurement data with 3D building footprints.

## Open the live application

<a class="vp-button vp-button-brand" href="/usecases/live/shadows">Live Use Case</a>

## Overview

The application combines:

- accumulated shadow CSV measurements per road segment
- OpenStreetMap building footprints fetched via Overpass API
- shadow heatmap, per-building shadow, and contribution views
- month-by-month temporal exploration
- GPU-accelerated shadow shader rendering
