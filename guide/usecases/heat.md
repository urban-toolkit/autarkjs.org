# Land Surface Heat Analysis

This case study explores **urban heat island effects** in Niterói, Brazil, combining land surface temperature raster data with OpenStreetMap road networks.

## Open the live application

<a class="vp-button vp-button-brand" href="/usecases/live/heat">Live Use Case</a>

## Overview

The application combines:

- 24-year land surface temperature raster (GeoTIFF)
- OpenStreetMap road network fetched via Overpass API
- thematic road coloring by LST exposure
- linked chart views
- browser-based spatial database and computation
