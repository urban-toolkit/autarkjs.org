# Examples

Explore interactive examples built with **Autark**.

Each example demonstrates how different modules — such as **autk-db**, **autk-map**, **autk-plot**, and **autk-compute** — can be combined to create powerful, browser-based spatial data applications.

From simple GeoJSON visualization to advanced analytical workflows, these examples showcase the flexibility and modularity of the Autark ecosystem.
