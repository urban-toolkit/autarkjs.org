# Urbane - 3D NYC Neighborhood Explorer

Urbane is a browser-based urban visual analytics case study built with **Autark**. It combines spatial data management, 3D map visualization, linked plots, and on-demand computation into a single interactive experience.

## Overview

This case study explores **New York City neighborhoods** through an integrated interface that combines:

- a full-screen interactive 3D map
- neighborhood-level thematic analysis
- parallel coordinates
- linked tabular views
- dynamic exploration of multiple datasets
- on-demand computation of quality targets
